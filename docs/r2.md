# Media storage on Cloudflare R2

Browsers upload photos directly to R2 through presigned `PUT` URLs. The app never proxies image bytes.

## Buckets

| Environment       | Public bucket (`pets/…`) | Private bucket (`reports/…`) |
| ----------------- | ------------------------ | ---------------------------- |
| Production        | `tecverde-public`        | `tecverde-private`           |
| Preview and local | `tecverde-dev-public`    | `tecverde-dev-private`       |

- Enable public access only on the public bucket. Use its `r2.dev` URL until the custom domain (`media.<domain>`) exists, and set it as `NEXT_PUBLIC_MEDIA_BASE_URL`.
- Never enable public access on a private bucket. Staff, reporters and tracking-link holders see report photos through 10-minute presigned `GET` URLs.
- Create one API token per environment with **Object Read & Write** limited to that environment's two buckets.

## Keys

- `reports/<reportId>/<uuid>.webp` for report photos, before and after the repair.
- `pets/<petId>/<uuid>.webp` for the adoption gallery.

The entity id is the draft id that the server reserves before the first upload, so keys never change after the entity is created. Objects are immutable and uploaded with `Cache-Control: public, max-age=31536000, immutable`.

## Upload contract

1. The browser decodes the photo, applies its orientation, resizes the long edge to 1600 px and re-encodes it as WebP at quality 0.82. Re-encoding removes EXIF and GPS metadata.
2. `createUploadIntent` validates the draft token (or the staff permission), the file count, the declared size (2.5 MB maximum) and the `image/webp` type. It then inserts `pending` media rows and signs `Content-Type`, `Content-Length` and `Cache-Control`. R2 rejects a request whose headers do not match with `403 SignatureDoesNotMatch`.
3. On submit, the server checks each object with `HeadObject` and reads its first 12 bytes to confirm the `RIFF…WEBP` signature before linking it to the report or pet.
4. The `cleanup-media` schedule deletes `pending` uploads older than 24 hours, plus the media of reports and pets soft-deleted more than 30 days ago.

## CORS

Apply this policy to each bucket, replacing the origins per environment. Add `GET` to the private buckets only if staff tools need to fetch objects from the browser.

```json
[
  {
    "AllowedOrigins": ["https://<production-origin>"],
    "AllowedMethods": ["PUT"],
    "AllowedHeaders": ["content-type", "cache-control"],
    "MaxAgeSeconds": 3600
  }
]
```

Development buckets allow `http://localhost:3000` and the preview origins instead.

## Environment variables

`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_PUBLIC_BUCKET`, `R2_PRIVATE_BUCKET` and `NEXT_PUBLIC_MEDIA_BASE_URL`. When any of the server variables is missing, the forms hide the photo picker and still accept submissions without photos.
